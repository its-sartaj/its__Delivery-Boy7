# 🛵 Indian Delivery Boys — The Hustle Anthem

> "हर ऑर्डर में एक कहानी है" — An immersive web app celebrating Indian delivery riders with Bollywood bangers, bike horn controls, tapri chai breaks, order notifications, and rider stats.

## ✨ Features
- 🎵 **80+ Curated Bollywood Hits**: 90s Classics, 2000s Hits, and Modern Chartbusters.
- 🔗 **Circular Doubly Linked List Engine**: Seamless $O(1)$ song navigation (Prev ⏮ / Next ⏭) with 15s auto-play protection.
- 📯 **Authentic Street Sounds**: Bike horn, order notification dings, and idling engine sounds powered by Web Audio API.
- ☕ **Tapri Chai Break**: 5-minute break timer modal with relaxation vibes.
- 🧾 **Delivery Receipt Generator**: Realistic printable order slip generator.
- 🌙 **Day & Night Mode**: Dynamic animated city skyline with rain and streetlight effects.
- 📱 **PWA Ready**: Mobile-first design with MediaSession API lock-screen audio controls.

## 🚀 Live Demo
Deployable on Vercel, Cloudflare Pages, and Netlify with zero configuration.
