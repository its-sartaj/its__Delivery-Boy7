# 🛍️ Misho (Meesho Clone)

Misho is a fully functional frontend clone of India's favorite online shopping destination, Meesho. It is built entirely using vanilla web technologies (HTML, CSS, JavaScript) and utilizes `localStorage` for state management, meaning no backend or database setup is required to run it!

## ✨ Features

- **Dynamic Product Listing**: Browse products across various categories (Women Ethnic, Men, Electronics, Beauty, etc.).
- **Shopping Cart**: Add items to your cart, update quantities, and view your total price with simulated discounts.
- **Admin Panel**: A dedicated seller/admin dashboard to manage the platform.
  - **Dashboard**: View overall stats like total revenue, active users, and recent orders.
  - **Manage Products**: Add new products, edit existing ones, or delete them.
  - **Manage Users**: Register new users, assign roles (Admin/User), and update their information.
- **Local Database**: All data (Products, Cart, Users) is stored securely in your browser's `localStorage` so it persists across page reloads.
- **Responsive Design**: Clean and modern UI modeled after the original Meesho app.

## 🚀 How to Run

Since this is a client-side only application, getting it running is incredibly simple:

1. Clone this repository or download the files.
2. Open the `index.html` file directly in any modern web browser (Google Chrome, Firefox, Edge, etc.).
   - *No Node.js, Python, or local servers required!*
3. To access the Admin Panel, click on the **"Seller/Admin Panel"** link in the header or navigate to `index.html#/admin`.

## 🛠️ Technologies Used

- **HTML5**: For page structure.
- **CSS3**: For styling, responsive layout, and animations.
- **JavaScript (ES6)**: For DOM manipulation, routing, and `localStorage` data management.
